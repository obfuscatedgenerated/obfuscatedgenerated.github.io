    Interface UserspaceSpawnedProcessContext

    The userspace proxy of a process the program spawned. The spawner is responsible for it, so unlike UserspaceOtherProcessContext, it can kill it and listen for its exit.

    interface UserspaceSpawnedProcessContext {

    }
